# 창의융합프로그램 신청자 명단 점검

창의융합교육센터 주말 프로그램의 통합예약시스템 신청 명단을 받아
중복·단체·대상 학년·관외·신청 제한·입력 오류·학부모 연락처를 자동으로 점검하고,
출석부·연락처 명렬표·결석 기록까지 관리하는 웹앱입니다. 2~3명이 함께 처리 상태를 보며 작업합니다.

- 사용 방법: 웹앱 위쪽 **[? 도움말]** — 한 주 흐름을 시점별로 안내 (「지금 할 일」 자동 표시, 인쇄 가능)
- 설치 방법: [guide/설치안내.md](guide/설치안내.md)
- 명단 받기 즐겨찾기 버튼: [xleesjx/excel-down](https://github.com/xleesjx/excel-down) (관리자 화면 → 이 웹앱 창으로 바로 보내기)
- `docs/` — GitHub Pages가 보여 주는 웹 화면 (`config.js`에 주소 두 개만 입력)
- `gas/` — 구글 시트의 Apps Script에 붙여넣는 서버 코드
- `test/` — 가짜 명단으로 하는 자동 테스트 (`npm test`, 화면 시험 `test/ui-smoke.js`, 즐겨찾기 버튼 연동 시험 `npm run test:cms`)

판정 로직은 `docs/core.js` 하나에 있고, `npm run build`로 `gas/Core.gs`에 복사합니다.

## 나중에 할 일 (보류)

- **자료가 쌓였을 때 속도**: 지금은 열 때마다 시트 전체를 읽습니다 (1년이면 통합명단 약 6,000줄).
  - 가짜 1년치 데이터로 먼저 속도를 재 보고,
  - 4주 지난 회차 자료(통합명단·처리기록·업로드기록·출석부 지난 차수)를 「보관_연도」 탭으로 자동 이동 (여러 주짜리 수업은 끝날 때까지 유지),
  - 신청 제한 계산은 최근 결석만 읽기, 바뀐 것이 없으면 서버 계산 결과 다시 쓰기(캐시).
- **개인정보 정리**: 학년도가 끝난 뒤 지난 자료의 연락처 지우기 또는 보관 탭 내려받기 후 삭제 기능.
- **운영 시기(기수)별 설정 묶음**: 1년 4시기(상반기 주말 · 여름방학 · 하반기 주말 · 겨울방학)마다 접수 방식·수업일·반·안내줄 단계를 따로 묶기.
  - 주말(상·하반기): 매주 토요일 수업, 그 주 화 10:00 접수 시작, 목 16:00 취소 기한, 1회 체험 (마스터반만 연속) — 지금 만든 방식.
  - 방학(여름·겨울): 평일 2주, 오전만 5개 반, 1주 창의·2주 SW, 한 주치를 한꺼번에 모집. 예) 2027 겨울: 1/18~22 · 1/25~29 수업, 1주차 모집 1/12(화) 10:00, 2주차 모집 1/13(수) 10:00. 접수 양식도 다름.
  - 지금 안내줄의 단계 시각(접수 시작·취소 기한)은 설정값이라, 시기별 규칙으로 늘리기 쉽게 되어 있음.
- **목요일 취소 기한 안내 문자용 연락처 엑셀**: 승인 학생 보호자(같은 번호는 한 번), 반 골라 받기. 문자 사이트 업로드 양식을 받은 뒤 만들기.
- **구글 시트로 바로 보내기**(검토만 함): 즐겨찾기 버튼이 웹앱 창 없이 사람별 「연결 키」로 서버에 바로 올리는 방식. 지금 방식(두 창 연결)을 써 보고 불편하면 진행.
